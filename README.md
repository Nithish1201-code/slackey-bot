# Slackey

A basic Slack bot that I made as my first time coding in JavaScript and working with bots.

It has a few simple slash commands for useful and random stuff like getting the current time, rolling a dice, flipping a coin, asking the magic 8ball and getting jokes from an API.

### Commands

| Command          | What it does                 |
| ---------------- | ---------------------------- |
| `/slackey-ping`  | Pings the bot                |
| `/slackey-roll`  | Rolls a dice                 |
| `/slackey-time`  | Gives the current time       |
| `/slackey-coin`  | Flips a coin                 |
| `/slackey-8ball` | Ask the magic 8ball anything |
| `/slackey-about` | Shows basic info             |
| `/slackey-joke`  | Tells you a joke             |

### What I learned

This was my first time coding in JS and also my first time dealing with bot hosting in general.

My friend had a VPS lying around so I decided to use that instead of something like Nest. Setting everything up and getting the services running was a bit difficult at first but I managed to pull through.

I learned a lot about JavaScript, Slack bots, APIs and hosting services while making this. It was a pretty simple project but it was a good first step into working with bots and deploying things myself.
